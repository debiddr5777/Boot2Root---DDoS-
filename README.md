
# Network Stress Testing Tool

This tool simulates a network stress test on a target URL by generating concurrent HTTP requests while monitoring system resources. It also checks for DDoS protection before running the test.

## Features
- ASCII art welcome screen
- DDoS protection check (Cloudflare, Akamai, AWS Shield)
- Simulated HTTP requests with response time logging
- Real-time CPU and memory monitoring
- Configurable threading level on a scale of 1 to 5 (1 = 10 threads, 5 = 50 threads)
- Graceful shutdown on Ctrl+C

## Requirements
- Python 3.x
- Libraries: `requests`, `psutil`, `colorama`
